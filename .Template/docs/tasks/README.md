# 作業単位ファイル（docs/tasks/）

`docs/overview.md`（プロジェクト全体・永続的な目的）とは別に、**個別の機能・作業に取り掛かるたびに**
このフォルダに1ファイルを作成する。作業完了後も削除せず、履歴として残す。

## 命名規則

```
docs/tasks/[YYYYMMDD]-[作業タイトル].md
```

例: `docs/tasks/20260711-add-login.md`

## フォーマット（1作業＝1ファイル）

```markdown
## 要求
<!-- 何を・なぜ。受け入れ条件があれば書く -->

## 設計
<!-- 実装アプローチ。変更するコンポーネント・影響範囲 -->

## タスクリスト
- [ ] ...
- [ ] ...
```

## 運用ルール

- 各セクション作成後の人間承認ゲートは**設けない**（`CLAUDE.md` のLoop Engineering方針に従い、
  完了条件はDefinition of Doneの検証コマンドで機械的に判定する）
- 大きな設計変更で `docs/overview.md`（プロジェクト全体の目的）自体に影響する場合のみ、そちらも更新する
- 図表が必要な場合はファイル内に直接 Mermaid 記法で埋め込む（別フォルダは作らない）
